### RÈGLES GÉNÉRALES
Validations et messages complémentaires
Ce guide présente les validations effectuées par le MEV-WEB ainsi que les messages d’erreur pouvant résulter de ces validations. Il est divisé en quatre sections :
• Validations d’autorisation (messages 9000 à 9099)
– Principes, messages d’erreur et validations effectuées relativement à l’autorisation permettant à un utilisateurde soumettre des requêtes de communication (validations de contexte).
• Validations de la structure d’une requête (messages 9100 à 9399)
– Principes, messages d’erreur et validations effectuées relativement à la structure des requêtes (reconnaissance d’une requête, validations unitaires et validations de cohérence).
• Validations du contenu des requêtes (messages 9400 à 9599)
– Principes, messages d’erreur et validations effectuées relativement au contenu des requêtes (validations unitaires et validations de cohérence).
• Messages complémentaires (9999)
– Messages d’information pouvant accompagner certains messages d’erreur.
NOTE Si une requête est soumise avec succès, le MEV-WEB transmet le code de statut HTTP « 200 OK » ou « 201 Created » au SEV. Si la requête soumise contient une ou des erreurs, le MEV-WEB transmet les messages nécessaires présentés dans ce guideainsi que le code de statut HTTP « 400 Bad Request » au SEV.

Codes de retour
Un code de retour est associé à chaque message d’erreur transmis par le MEV-WEB en réponse à une requête. Ce code contient deux chiffres : le premier (1 ou 9) indique si l’erreur est associée aux renseignements saisis par l’utilisateur (1) ou à la version du SEV utilisée (9), et le second (0 à 6) indique l’origine du message d’erreur.
IMPORTANT Si votre SEV reçoit un message d’erreur, pour une transaction, dont le code de retour se termine par «0 », « 1» ou « 5», celle-ci est considérée ne pas avoir été transmise. Dans un tel cas, votre SEV doit la retransmettre dans un lot lors de la prochaine requête de type « transaction ».
NOTE Le code de retour « 00» indique que l’erreur n’est pas associée à l’utilisateur ni à la version du SEV.
