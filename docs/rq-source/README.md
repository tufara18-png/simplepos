# Documents source Revenu Québec

Documents officiels convertis en Markdown, fournis par l'utilisateur, pour éviter de les reperdre
d'une session à l'autre (ils vivaient auparavant seulement dans un dossier local, jamais commités).

- `SW-72(2025-03).md` — Erreurs fréquentes lors de la réalisation des cas d'essai en laboratoire
- `SW-73(2026-03).md`, `SW-73.A(2026-01).md`, `SW-73.B(2025-05).md`, `SW-73.D(2025-07).md` — guide
  technique MEV-WEB (format JSON, en-têtes, signature, modèles de documents, annexes)
- `SW-76(2025-06).md` — Renseignements généraux sur l'adaptation des SEV (guide public)
- `SW-77(2025-11).md` — Cas d'essais pour les concepteurs de SEV (cas numérotés)
- `SW-78(2026-06).md` — Cas d'essais complémentaires, déclaration de conformité (cas FO-1xx),
  converti depuis le `.docx` d'origine (texte + tableaux, pas de mise en forme ni d'images)
- `SW-79(2026-04).md` — Démarche pour l'obtention d'une certification

Voir `docs/certification-test-cases.md` pour le mappage de chaque cas à l'état réel du code.

**Volontairement exclus** : `SW-256` (transactions bancaires électroniques) et `SW-299` (bordereau
de paiement RL Z-1.S) — domaines sans rapport avec la certification MEV-WEB restauration de
Resto360, probablement inclus par erreur par l'outil de récupération de documents utilisé.

Les images des PDF d'origine (schémas illustratifs) n'ont pas été copiées, seul le texte — se
référer aux numéros de page cités dans chaque document si une figure précise est nécessaire.
