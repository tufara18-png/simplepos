Introduction
Ce guide présente des cas d’essais complémentaires que vous devez réaliser avec votre système d’enregistrement des ventes (SEV) afin d’obtenir notre certification dans le cadre des mesures sur la facturation obligatoire. Ces cas d’essais complémentaires permettent de vérifier si un SEV répond aux exigences énoncées dans le Guide d’adaptation des SEV (SW-73), et ce, conformément aux lois fiscales que nous appliquons, comme la Loi sur l’administration fiscale (RLRQ, chapitre A-6.002) et la Loi sur la taxe de vente du Québec (RLRQ, chapitre T-0.1).
Vous devez réaliser les cas d’essais complémentaires dont il est question dans ce guide avant de commencer les cas d’essais présentés dans le document Cas d’essais pour les concepteurs de SEV (SW-77). Notez que les certificats et les comptes à utiliser pour les cas d’essais complémentaires décrits dans le présent guide sont les mêmes que ceux utilisés pour les cas d’essais présentés dans le guide SW-77.
Les cas d’essais présentés dans ce guide doivent être réalisés dans l’environnement de développement (DEV).
À qui s’adresse ce guide?
Ce guide s’adresse à vous si vous souhaitez développer un SEV compatible avec la solution technologique mise en place dans le cadre des mesures sur la facturation obligatoire, ou si vous avez développé un SEV et que vous voulez l’adapter afin de le rendre compatible avec cette solution. Cette solution technologique, ci-après appelée MEV-WEB, consiste en un nouveau module d’enregistrement des ventes accessible par Internet au moyen des services en ligne prévus à cette fin.
Les appareils mobiles et les autres systèmes qui permettent de produire des factures doivent pouvoir communiquer avec le MEV-WEB. Cette communication entre votre SEV et le MEV-WEB doit se faire selon une structure de communication qui est expliquée dans le guide SW-73.
Pour plus de renseignements, consultez la section Partenaires de notre site Internet à revenuquebec.ca.
Important
Ce guide explique uniquement la procédure à suivre pour obtenir la certification d’un SEV.
Quand ce guide est-il mis à jour?
Le présent guide est en constante évolution. Son contenu est mis à jour lorsque toute nouvelle information susceptible d’avoir une incidence sur vos travaux est disponible. Notez que chaque changement apporté au présent guide est surligné en jaune.

Comment réaliser les cas d’essais complémentaires
Préalables
Dans le cadre de la demande de certification de votre produit, les cas d’essais complémentaires dont il est question dans le présent guide doivent être réalisés dans l’environnement de développement avant les cas d’essais présentés dans le guide SW-77. Notez que les comptes à utiliser pour les cas d’essais complémentaires décrits dans le présent guide sont les mêmes que ceux utilisés pour les cas d’essais présentés dans le guide SW-77. Cependant, contrairement aux cas d’essais du guide SW-77, qui demandent deux appareils distincts, vous devez réaliser les cas d’essais complémentaires de ce guide au moyen d’un seul appareil.
Environnement
Pour réaliser les cas d’essais complémentaires dont il est question dans ce guide, vous devez utiliser l’environnement de développement (« DEV »). Notez que l’environnement d’essais (« ESSAI ») est consacré aux cas d’essais décrits dans le guide SW-77. Les adresses des environnements sont listées dans celui-ci.
Vous devez utiliser les informations présentées dans la partie 2.1.2 du guide SW-77. Assurez-vous de les rendre disponibles dans l’environnement de développement (« DEV »). Pour les rendre disponibles, vous pouvez les créer dans l’environnement de développement (« DEV ») en suivant les instructions données aux parties 3.2 et 3.3 du guide SW-77.
Identification des cas d’essais
Selon les spécifications données dans le guide SW-73, le champ d’en-tête CASESSAI est utilisé pour identifier les cas d’essais présentés dans le guide SW-77. Pour les cas d’essais complémentaires décrits dans le présent guide, ce champ n’est pas utilisé et doit donc toujours avoir la valeur « 000.000 ».
Réalisation des cas d’essais
Pour l’obtention d’une première certification, vous devez réaliser tous les cas d’essais obligatoires ainsi que ceux relatifs aux fonctionnalités additionnelles qu’offre votre SEV. 
Pour l’obtention de la certification d’une version subséquente de votre SEV, vous devez réaliser les cas d’essais obligatoires ainsi que ceux relatifs aux fonctionnalités qui n’étaient pas offertes par votre SEV lors de la demande de certification précédente. Les cas d’essais obligatoires lors d’une nouvelle demande de certification sont les suivants :
Cas FO-104 : Transmettre, à la suite d’une déconnexion, une facture produite en mode Hors ligne
Cas FO-105 : Transmettre une facture produite en mode Hors ligne
Cas FO-106 : Transmission sur demande et transactions en attente
Cas FO-107 : Afficher les messages d’erreur générés par le MEV-WEB
Cas FO-109 : Conserver et supprimer un certificat
Cas FO-110 : Produire des rapports
Cas FO-114 : Ajouter et supprimer des items
Cas FO-115 : Annuler une transaction
Cas FO-116 : Produire une note de crédit liée à une facture
Cas FO-117 : Produire une facture en mode Formation
Cas FO-132 : Gestion de la taille maximale d’un lot de transactions (256 ko)
Lorsque vous aurez rempli toutes les zones de résultats de ce document, vous devrez le joindre, accompagné des pièces exigées, à la demande de certification à transmettre à partir de Mon dossier pour les partenaires – Facturation obligatoire, accessible sur notre site Internet, à revenuquebec.ca. Pour tous les détails concernant la démarche à entreprendre pour obtenir une certification pour votre SEV, consultez le document Démarche pour l’obtention d’une certification (SW-79).
Par ailleurs, lorsque l’icône ci-contre figure dans un cas d’essais, cela signifie que vous devez téléverser, avec votre demande de certification, la copie des données demandées en format ZIP. Le fichier doit être nommé en fonction du numéro du cas d’essais. Par exemple, si vous devez téléverser un fichier ZIP pour le cas d’essais FO-119, ce fichier doit être nommé « FO-119.zip ».
